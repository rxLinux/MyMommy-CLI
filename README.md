MyMommyCLI 💖

Sua mommy programadora no terminal.
Uma CLI de IA com personalidade, capaz de conversar, planejar e executar tarefas diretamente no seu computador.

✨ O que é?

A MyMommyCLI é um agente de IA para terminal inspirado em ferramentas como Codex CLI e Claude Code, mas com sua própria identidade.

Ela entende seu projeto, conversa naturalmente, cria arquivos, edita código, executa comandos, roda testes e acompanha todo o fluxo de desenvolvimento — tudo diretamente pelo terminal.

Enquanto trabalha, ela explica cada passo antes de agir, para que você sempre saiba o que está acontecendo.

📌 Filosofia

A MyMommyCLI foi criada para parecer menos uma ferramenta e mais uma companheira de programação.

Ela explica o que está fazendo, acompanha seu raciocínio e mantém uma conversa natural durante todo o processo, sem deixar de ser objetiva quando precisa executar tarefas.

O foco é oferecer uma experiência agradável sem abrir mão da produtividade.
